# Mateo Espinosa — portfolio

Interactive Vite + React portfolio with a local guide grounded in the content of the site.

## Local setup

```bash
npm install
npm run dev
```

The portfolio guide runs entirely in the browser. It searches the structured profile and project
data with Fuse.js, then builds controlled English or Spanish responses from that content. It does
not require an API key, server route, model download or external AI service.

## Checks

```bash
npm test
npm run lint
npm run build
```
